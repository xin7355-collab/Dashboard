這些數字是怎麼來的、又有哪些限制

  • Git 內容來自 GitHub API 的 repository.size。這是 GitHub 定期估算的磁碟用量，不是即時值，剛 push 完可能要一段時間才反映。
  • Actions artifacts 與 Packages 共用同一份儲存額度，這通常才是空間爆掉的主因，而不是程式碼本身。
  • Actions cache 每個 repository 各有獨立額度、滿了會自動淘汰最舊的，因此不計入「總佔用」，但仍單獨列出。
  • Release 附件不計入儲存額度，但會消耗下載頻寬。
  • Git LFS 的 REST API 沒有逐 repository 的用量端點，只能從帳單取得總量；儀表板改以 .gitattributes 標示哪些 repository 有在用。
  • 額度上限寫在 config.json，是各方案的參考值。GitHub 的計費政策會變動，請對照你帳號 Settings → Billing 的實際數字調整。
  • 用滿預估是對最近 30 天做最小平方線性外推。R² 低於 0.5 時會標示為不可靠——成長多半是階段性的，別把它當承諾。

公開快照由 GitHub Actions 每日產生並存進本 repository。私人 repository 與帳單資料只在你按下「即時掃描」時於瀏覽器端抓取，權杖與結果都只存在這台裝置。

用你自己的權杖做即時掃描

快照模式只看得到公開資料。貼上個人存取權杖後，儀表板會直接從你的瀏覽器打 GitHub API，補上私人 repository、Git LFS 與帳單用量。

權杖不會離開這台裝置——不會送到任何伺服器，也不會寫進這個 repository。

建立 fine-grained 權杖時需要的權限：

  1. 到 Settings → Developer settings → Fine-grained tokens
  2. Repository access 選 All repositories
  3. Repository permissions：Metadata: Read、Actions: Read、Contents: Read
  4. Account permissions：Plan: Read（帳單用量需要）
